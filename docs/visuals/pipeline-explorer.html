Local-first is not offline

English Whisper and semantic search run on the host. Hinglish audio uses Sarvam. Groq may receive text, retrieved excerpts, prompts, and optional sampled images.

Private single-user design

The service has no login. Its owner/rate-limit identity is derived from client IP. Keep it on localhost or add real authentication and authorization before network exposure.
